# CINELIT — Cine Art Dept

Installable web and desktop browser app for covers, film props, packaging, signs and quick mockups. Projects are stored on your device; export project files for backups.

Open the hosted link in Safari or Chrome. On phones use Add to Home Screen; on supported desktop browsers use Install app or Add to Dock. PNG, JPEG, PDF and SVG exports are supported.

Physical print and carton folding require your own proof.
