# CINELIT — Cine Art Dept

Installable web and desktop browser app for covers, film props, packaging, signs and quick mockups. Projects are stored on your device; export project files for backups.

Open the hosted link in Safari or Chrome. On phones use Add to Home Screen; on supported desktop browsers use Install app or Add to Dock. PNG, JPEG, PDF and SVG exports are supported.

Physical print and carton folding require your own proof.

## Screens

Choose Screens from Collection for search engines, social feeds, photo profiles, chats, email, video/streaming, news, maps, shops, banking, calendars, terminals, calls, browser and desktop interfaces. Twenty new fictional screen props are editable and support still images plus short animated clips.

Use Content to edit copy and Artwork to upload an image. Under Design set video motion, duration and amount. Preview screen motion shows the animation. Choose Video / animated screen to export a 3–30 second MP4 or WebM (actual format depends on browser support), up to 1920 pixels on the longest edge. Keep the app visible during export. PNG/JPEG/PDF/SVG still exports remain available.

Screen editability pass: all 20 current screen templates expose editable interface labels, menus, counters, timestamps/row details and author/sender lists, alongside main copy/colour controls. Artwork has separate photo-grid/thumbnail slots and avatars where used. Older five screen formats are hidden from the catalogue but retained for loading saved projects. Template selection waits for initial project loading so quick clicks cannot be overwritten.


### Screen appearance controls
All 20 Screens templates include Colour palette, Screen softness and Screen pixelation in Design. Set both sliders to zero for a clean screen. Choose a palette or edit background, text and accent colours individually. Appearance effects carry through still-image and video exports; SVG with these effects embeds a raster image to preserve the appearance. Saved projects remain editable.

## November 1 — graphic design and detailed Screens

Search home/results, social feed, microblog and photo profiles have richer editable layouts and interface copy. All twenty Screens now use original geometric/editorial graphics in empty artwork slots. Uploaded artwork still replaces those graphics. New-project and optional sample artwork is graphic design, not an AI photograph. Existing saved artwork is preserved.

PNG/JPEG exports now support native, 2× and 3× render scales (24-megapixel / 8192-edge limit). Type and geometry are re-rendered; raster source detail is not invented. All catalogue exports retain existing controls. Larger print/on-camera acceptance still needs a production-size review.

## November 4 — Search screen studio

Screens → Search engine — home/results now provides Google-style SEEK and DuckDuckGo-style Wren layouts. Search layout and Search view are available above the editor tabs. Starting style supplies ten complete variations, including compact research and night mode.

Web, Images, News, Videos and Maps/local-place result pages have editable fictional copy and original vector graphic defaults. Web results include distinct source identities, URLs, timestamps, snippets, sitelinks, optional answer summary, knowledge panel, related questions/expanded answer, related searches, optional top stories and sponsored results. Home offers autocomplete and an optional uploaded logo. Optional browser tabs/address bar and region/date/safe-search/language labels complete the insert. Uploaded art can replace defaults, including knowledge-panel imagery/maps.

These are production screen-prop designs, not a live web search service. No photorealistic AI images were added. Still/vector/PDF and animated video exports retain the existing app workflows.
